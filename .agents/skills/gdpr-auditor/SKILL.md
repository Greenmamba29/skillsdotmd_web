# GDPR Auditor Agent

## When to use
Use this skill to audit web applications and data processing workflows for GDPR, CCPA, and other privacy regulation compliance before launch or during periodic reviews.

## Instructions
1. Map all personal data collection points in the application
2. Audit cookie consent implementation and consent management platform
3. Review privacy policy for completeness against GDPR Article 13/14 requirements
4. Check data retention policies and deletion workflows
5. Verify data subject rights implementation (access, deletion, portability)
6. Audit third-party data processors and DPA agreements
7. Generate GDPR compliance checklist with remediation priorities

## Environment
- Runtime: ubuntu-22
- Trigger: Manual
- Category: Security & Compliance Agents

## Examples
- GDPR audit for a new SaaS product before EU launch
- CCPA compliance review for a California-facing ecommerce site
- Cookie consent audit and remediation for a marketing website
