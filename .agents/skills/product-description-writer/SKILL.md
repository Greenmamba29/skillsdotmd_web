# Product Description Writer Agent

## When to use
Use this skill to create compelling product descriptions that improve search rankings and drive conversions for new or existing ecommerce product listings.

## Instructions
1. Accept product name, category, key features, and target audience as input
2. Research competitor listings and identify top-performing keywords
3. Write a hook headline optimized for the platform (Amazon A+ vs Shopify)
4. Craft a benefit-driven description highlighting USPs over features
5. Add SEO keywords naturally throughout the copy
6. Generate bullet points for scannable feature highlights
7. Include a clear call-to-action and urgency triggers

## Environment
- Runtime: node-20
- Trigger: Manual
- Category: Marketplace & Ecommerce Agents

## Examples
- Write 50 product descriptions for a new Shopify electronics store
- Optimize existing Amazon listings for better search visibility
- Generate descriptions for a WooCommerce fashion boutique
