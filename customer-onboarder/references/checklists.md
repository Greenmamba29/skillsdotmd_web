# Onboarding Checklist Templates

## Standard SaaS Checklist (saas_standard)

### Customer Tasks
1. Log in and set temporary password
2. Complete company profile
3. Invite team members (enterprise: 3+, smb: 1+)
4. Connect first integration
5. Complete product tour
6. Achieve first value milestone (segment-specific, see below)

### CSM Tasks
1. Send welcome email sequence (automated)
2. Conduct kickoff call
3. Share onboarding guide / training resources
4. Verify account configuration matches plan
5. First week check-in (call or async)
6. Confirm first value milestone achieved

## First Value Milestones by Segment

- **b2b_buyer**: First purchase order submitted through platform
- **b2b_supplier**: First catalog uploaded and published
- **smb**: First invoice sent or first report generated
- **enterprise**: First team workflow configured and executed
- **self_serve**: First core action completed (varies by product)

## Enterprise Add-On Tasks

### Customer
- Configure SSO / SAML
- Set up role-based access for team
- Complete data import / migration
- Run first admin report

### CSM
- Deliver admin training session
- Set up executive business review cadence
- Create custom success plan
- Share ROI tracking template

## Marketplace Add-On Tasks (b2b_buyer / b2b_supplier)

### Buyer
- Add payment method
- Set up approval workflows
- Submit first RFQ or purchase order

### Supplier
- Complete seller verification
- Upload product catalog
- Configure shipping / fulfillment settings
- Receive first order

## Checklist Completion Criteria

Onboarding is marked **complete** when:
1. All customer tasks are checked off
2. All CSM tasks are checked off
3. First value milestone is confirmed
4. Health score ≥ 50

If any task is blocked for 5+ days, trigger escalation to CSM and CS lead.
